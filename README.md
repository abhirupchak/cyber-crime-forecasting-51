# Cyber-Crime Forecasting and State Profiling (India, 2018–2022)

Machine Learning project (Problem 51): forecasting State/UT cyber-crime registrations and grouping States by growth profile, for cyber-police planning.

**Course:** B.Sc. (H) Computer Science, Semester VI — Machine Learning
**Author:** Abhirup Chakraborty (24020570039)

**Live dashboard:** https://abhirupchak.github.io/cyber-crime-forecasting-51/

## What this does

1. **Forecast** 2022 registrations from 2018–2021 with persistence, pooled OLS (State fixed effects + trend), ridge, and quadratic-ridge. Evaluated one year ahead.
2. **Relate** national totals to TRAI internet/tele-density and NPCI/RBI UPI penetration, and merge State-level tele-density (Problem 39) via TRAI service-area circles with a documented mapping.
3. **Cluster** States by five-year log-growth profiles using k-means and Ward hierarchical clustering.

## Key results (train 2018–2021, test 2022, 35 entities)

| Model | RMSE | MAE | R² |
|---|---|---|---|
| Persistence (2022 = 2021) | **1,359.8** | **580.8** | **0.861** |
| State mean 2018–21 | 1,994.0 | 730.0 | 0.702 |
| Pooled OLS (State effects + trend) | 1,909.6 | 717.8 | 0.727 |
| Ridge (alpha = 0.1) | 1,854.7 | 646.5 | 0.742 |
| Quadratic + Ridge (alpha = 1.0) | 2,569.5 | 967.0 | 0.505 |

- National CAGR 2018–2022: **24.7%** (27,248 → 65,893).
- log(cases) vs log(internet subscribers): **r = 0.981**; vs log(UPI volume): **r = 0.987**; vs tele-density: **r = −0.980** (denominator artefact).
- State-level tele-density merge adds little: ridge RMSE **1,833** vs 1,855 without it; 2022 cross-section **r = −0.03**.
- Silhouette peaks at k = 2 (0.607); k = 4 retained for planning (k-means 0.432, Ward 0.464).

## Reproduce

```bash
pip install -r requirements.txt
python code/run_experiments.py   # writes all CSVs and figures to outputs/
python code/make_paper.py        # rebuilds the DOCX in paper/
python code/make_dashboard.py    # rebuilds the dashboard in docs/
```

Seed is fixed at 42. `datafile.xls` needs the `calamine` engine (installed via `python-calamine`).

## Data sources

- NCRB, *Crime in India 2022* / State-UT cyber-crime cases 2018–2022, OGD Platform India (GODL-India).
- TRAI, *Indian Telecom Services Performance Indicators* (yearly 2019–2021; quarterly Oct–Dec 2022).
- NPCI / RBI, UPI volumes and Annual Reports.

## Caveats

Registered cases reflect reporting, not true incidence. Clusters are operational groupings for resource planning, not rankings of State safety. National-level penetration correlations are ecological and not transferable to individuals.
